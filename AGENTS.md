## Agent skills

### Coding standards

Before writing or reviewing code, tests, or technical documentation,
read `docs/agents/coding.md`.

### Git conventions

Before creating branches, writing commits, pushing, or merging,
read `docs/agents/git.md`.

### Issue tracker

Track issues and specs in GitHub Issues. Before reading or publishing
tickets, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. Before triaging or changing labels,
read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout. Before exploring the codebase,
read `docs/agents/domain.md`.
