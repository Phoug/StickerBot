# Sticker Studio / StickerBot

Telegram Mini App для создания стикерпаков, фото- и видеостикеров. Вход — через проверенные Telegram Mini App initData. Телефон, коды входа, Telethon и пользовательские сессии не используются.

## Сценарий

1. Открыть Mini App кнопкой в боте.
2. Создать набор с названием или вставить ссылку на существующий обычный набор.
3. При импорте создаётся **новый набор с новой ссылкой** и копиями стикеров. Оригинал не изменяется. Копируйте только свои работы или работы, на которые есть разрешение.
4. Открыть набор и добавить фото/видео из галереи или видео по публичной ссылке из соцсети.
5. Для видео выбрать фрагмент до 3 секунд ручками на ленте кадров. Настроить кадр перетаскиванием и двумя пальцами; выбрать исходные пропорции, квадрат, скругление или круг.
6. Посмотреть готовый стикер и добавить в набор. На открывшемся экране редактирования ввести эмодзи с клавиатуры, настроить порядок и сохранить изменения.
7. При необходимости удалить набор кнопкой корзины на его экране. После подтверждения набор удаляется из Telegram и приложения навсегда; исходный набор при удалении импортированной копии не затрагивается.

Редактор занимает высоту Mini App: предпросмотр и кнопка продолжения остаются на экране, настройки сгруппированы во вкладках «Фрагмент», «Кадр», «Форма». Фото и видео можно перемещать пальцем и увеличивать двумя пальцами с сохранением точки под пальцами. Ползунков нет: видео обрезается ручками на ленте кадров. Для мыши и клавиатуры доступны кнопки масштаба, стрелки и сброс кадра.

Новый пустой набор хранится как черновик: Telegram требует хотя бы один стикер при создании. После первого сохранения появляется ссылка на набор.

Импорт поддерживает обычные наборы до 120 стикеров, включая статические, TGS и видео. Новые стикеры создаются из видео и фото JPEG/PNG/WebP. Статические и видеостикеры импортированной копии можно открыть в редакторе и заменить на прежнем месте; Прозрачность оригинального видеостикера сохраняется при повторной обработке. TGS-редактор не поддерживается. Маски и custom emoji не импортируются. Незавершённый импорт можно продолжить с экрана набора. Авторство внешнего набора автоматически не проверяется.

## Структура

- `app/bot/` — aiogram, команды и кнопка открытия Mini App; прежние команды загрузки и конвертации сохранены.
- `app/webapp/` — HTML, CSS и JavaScript, без сборщика.
- `backend/routers/stickers.py` — наборы, импорт, превью из Telegram.
- `backend/routers/studio.py` — загрузка, обработка, предпросмотр, публикация.
- `backend/services/media/` — yt-dlp и FFmpeg.
- `backend/storage.py` — SQLite, привязка наборов и файлов к Telegram user ID.
- `data/` — приватная база и временные медиа; не доступны через static и не коммитятся.

## Локальный запуск

Нужны Python 3.11+, FFmpeg с libx264 и libvpx-vp9, ffprobe.

```powershell
py -m venv .venv
.venv/Scripts/python -m pip install -r app/requirements.txt -r backend/requirements.txt
.venv/Scripts/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
# Во втором терминале:
.venv/Scripts/python run_bot.py
```

Настройки передаются через окружение или локальный приватный конфигурационный файл:

| Переменная | Назначение |
| --- | --- |
| BOT_TOKEN | Токен бота; одинаковый для API и бота |
| API_SECRET_TOKEN | Общий секрет для прежних серверных медиаэндпоинтов |
| VIDEO_API_URL | Для бота: локально http://127.0.0.1:8000, в Compose задаётся автоматически |
| WEBAPP_URL | Публичный HTTPS-адрес Mini App с путём /app/ |
| DATA_DIR | Каталог базы и медиа; по умолчанию ./data |
| MINI_APP_AUTH_MAX_AGE | Срок приёма initData в секундах, по умолчанию 86400 |

TELEGRAM_API_ID, TELEGRAM_API_HASH и TELETHON_SESSIONS_DIR больше не нужны. Старые файлы сессий не используются приложением; они исключены из Git и Docker.

Mini App доступен на `/app/`, health check — `/health`. Для Telegram нужен публичный HTTPS-адрес: reverse proxy должен передавать и `/app/`, и `/api/` на FastAPI. При открытии вне Telegram приложение показывает подсказку и не предоставляет доступ к данным. Если сессия истекла, закройте и заново откройте Mini App.

## Ограничения первой версии

- Видео до 50 МБ, 10 минут и 4096×4096; для редактора перекодируется в MP4 до 1280px без звука.
- Видео: до 3 секунд, VP9/WebM до 256 КБ, без звука. Фото: WebP до 512 КБ, загрузка до 40 мегапикселей; EXIF-поворот применяется автоматически. По умолчанию сохраняются пропорции: длинная сторона 512px. Квадрат, круг и скругление выбираются отдельно; у масок прозрачные углы, прозрачность фото сохраняется.
- Доступность скачивания зависит от соцсети, её ограничений и версии yt-dlp. Приватные видео, DRM и вход по cookies не поддерживаются.
- Исходники и предпросмотры доступны владельцу в течение часа. Просроченные файлы удаляются фоновым обслуживанием; наборы остаются в базе.
- Тяжёлая обработка выполняется в пуле потоков, одновременно до двух операций. Пока без отдельной очереди задач: не закрывайте Mini App во время операции.
- API запускается **одним процессом / одним worker**. Для масштабирования понадобится общая очередь и распределённая блокировка.
- Готовые стикеры открываются в крупном просмотре. Можно удалить отдельный стикер с подтверждением или изменить порядок в режиме «Изменить» (ручка перетаскивания, затем «Сохранить изменения»; на том же экране вводится эмодзи с клавиатуры). После ошибки сохранения приложение перечитывает фактический порядок из Telegram: часть перемещений могла уже примениться.
- Обложка набора берётся из Telegram, а при её отсутствии — из первого стикера. Для просмотра видеостикеров сервер создаёт временное H.264/MP4-превью, совместимое с iOS; оригинал в Telegram сохраняет VP9 и прозрачность. Для TGS показывается только миниатюра с пояснением.
- Интерфейс учитывает отдельно системную безопасную зону и отступы кнопок Telegram, включая их изменения. Проверка в локальном браузере имитирует эти зоны; финальная проверка конкретной версии Telegram выполняется на устройстве.
- При импорте сохраняются файлы и основной эмодзи; все дополнительные эмодзи и ключевые слова исходного набора Bot API не возвращает.
- Надёжность публикации зависит от ответа Telegram. Повторная отправка того же результата не должна дублировать стикер.

## Docker / CI/CD

Dockerfile устанавливает обе группы зависимостей. Один образ используется для FastAPI и бота с разными командами запуска. База и медиа API сохраняются в томе `sticker-data`; не удаляйте этот том при обновлениях.

### Локальная проверка текущей ветки через Docker Desktop

Запустите Docker Desktop в режиме Linux containers и дождитесь готовности Engine. Для разработки используйте отдельного тестового бота, если основной уже работает на сервере.

В приватной конфигурации задайте BOT_TOKEN, API_SECRET_TOKEN и WEBAPP_URL (публичный HTTPS-адрес с путём /app/). Секрет API должен совпадать для бота и API; Compose передаёт одни настройки обоим контейнерам.

Соберите именно текущий код, используя публичный Python-образ без авторизации в DHI:

```powershell
docker build --build-arg PYTHON_IMAGE=python:3.14-slim -t yavika/sticker-bot:local .
$env:IMAGE_TAG = "local"
docker compose -p stickerbot-dev up -d --pull never --wait
docker compose -p stickerbot-dev ps
```

Проверка API: http://localhost:8000/health. Интерфейс: http://localhost:8000/app/ (в обычном браузере доступ к личным данным закрыт). Для работы Mini App внутри Telegram нужен HTTPS-туннель к локальному порту 8000 или собственный HTTPS reverse proxy. Его публичный адрес укажите в WEBAPP_URL и затем пересоздайте контейнер бота той же командой Compose.

Логи и остановка без удаления базы:

```powershell
docker compose -p stickerbot-dev logs --tail 100 api bot
docker compose -p stickerbot-dev down
```

При сборках CI по умолчанию остаётся образ DHI. Тег local используется только на вашем компьютере, публикация в реестр не требуется.

### Развёртывание опубликованного образа

```powershell
$env:IMAGE_TAG = "main"
docker compose up -d
```

Workflow публикует образ и развёртывает Compose при пуше в main, версионном теге или ручном запуске. Изменения рабочей ветки автоматически не деплоятся. Автоматические тесты пока запускаются отдельно от deploy workflow.

## Проверки

```powershell
.venv/Scripts/python -m pip install -r tests/requirements.txt
.venv/Scripts/python -m pytest tests -q
node --check app/webapp/app.js
node --test tests/frontend.test.cjs
```

Тесты используют временную базу, фиктивный Bot API и тестовые initData. Реальные токены, пользовательские сессии и приватная конфигурация не читаются. Тесты FFmpeg проверяют фактические размер, длительность, кодек и прозрачность масок.

Для визуальной проверки на телефоне без реального Telegram можно запустить `.venv/Scripts/python tests/preview_server.py` и открыть http://127.0.0.1:8766/ (390×700) или http://127.0.0.1:8766/?size=compact (360×560). Это отдельный локальный стенд с тестовыми данными, подменой Telegram API и синтетическим видео; он не используется в Docker и CI/CD.

### Проверка в Telegram через ngrok (Windows / PowerShell)

1. Запустите Docker Desktop. Установите ngrok и подключите учётную запись (один раз):

   ```powershell
   ngrok config add-authtoken ВАШ_NGROK_AUTHTOKEN
   ngrok http 8000
   ```

   Оставьте этот терминал открытым. Скопируйте выданный HTTPS-адрес.
2. В локальной приватной конфигурации задайте `BOT_TOKEN`, `API_SECRET_TOKEN` и `WEBAPP_URL=https://ВАШ-АДРЕС.ngrok-free.app/app/`. Образец — `.env.example`. Старые настройки Telethon больше не нужны.
3. Из каталога проекта в другом терминале соберите и запустите текущий код:

   ```powershell
   docker build --build-arg PYTHON_IMAGE=python:3.14-slim -t yavika/sticker-bot:local .
   $env:IMAGE_TAG = "local"
   docker compose -p stickerbot-dev up -d --pull never --wait
   docker compose -p stickerbot-dev ps
   Invoke-RestMethod http://localhost:8000/health
   ```

4. Отправьте тестовому боту `/start` и нажмите новую кнопку Mini App. Если Mini App настроен также через BotFather, обновите там его URL на тот же HTTPS-адрес. На бесплатном ngrok при первом открытии может понадобиться нажать **Visit Site**.
5. Если адрес туннеля изменился, обновите `WEBAPP_URL`, повторите команду Compose и снова отправьте `/start`, чтобы получить кнопку с новым адресом.

Инструкция ngrok: https://ngrok.com/download/windows. Остановка: `docker compose -p stickerbot-dev down`; том с наборами сохраняется.

В редакторе набора можно ввести любой один эмодзи с клавиатуры (включая флаги, семейные эмодзи и оттенки кожи). Сервер проверяет ввод до загрузки в Telegram. Перестановка стикеров работает во время перетаскивания, с плавным перемещением соседних строк и прокруткой у края экрана. Системная настройка уменьшения движения отключает анимации.


Встроенный просмотр открывается в компактном диалоге, воспроизводит видео по кругу без системных видеоконтролов и поддерживает свайпы между стикерами. Тип файла обозначен в сетке и просмотре. При поддержке Telegram Mini Apps 8.0+ предлагается открыть приложение на весь экран; запрос выполняется по нажатию пользователя.

Медиа кэшируются на время сессии браузера (до 5 минут, 128 файлов / 100 МБ); переход на главный экран больше не сбрасывает обложки и предпросмотры. Сервер хранит скачанные файлы и MP4-превью в памяти до 5 минут, максимум 32 МБ / 256 записей, объединяя одинаковые одновременные запросы. Проверка владельца и принадлежности набору выполняется перед выдачей из кэша. Повторный предпросмотр с неизменными настройками использует готовый результат. После перезапуска API серверный кэш пуст; база и оригинальные наборы сохраняются.

Пересборка и перезапуск локальных контейнеров из текущей ветки (PowerShell):

```powershell
docker build --build-arg PYTHON_IMAGE=python:3.14-slim -t yavika/sticker-bot:local .
$env:IMAGE_TAG = "local"
docker compose -p stickerbot-dev up -d --pull never --force-recreate --wait
docker compose -p stickerbot-dev logs --tail 100 api bot
```


Фото по ссылке: поддерживаются прямые публичные HTTPS-ссылки на JPEG/PNG/WebP и фотопубликации TikTok, в том числе карусели до 35 фото. Карусель открывается сеткой миниатюр: выберите снимок для редактора; возврат из редактора снова открывает выбор. Видео из соцсетей загружаются прежним способом. Обложки видео и фоновая музыка не подменяют фотографии. Приватные публикации и обход авторизации не поддерживаются; доступность TikTok зависит от региона, защиты сайта и формата страницы.

Загрузка фотопубликации ограничена 50 МБ исходников, 50 МБ подготовленных фото и 120 секундами на скачивание/подготовку снимков. При ошибке частично импортированные фото удаляются. Прямые ссылки и редиректы проверяются; сетевое соединение запрещает локальные и приватные IP-адреса. Миниатюры доступны только владельцу.

В редакторе отключаются вертикальные жесты сворачивания Telegram через API 7.7+, при выходе обычное поведение восстанавливается. Жест за заголовок самого Telegram остаётся под управлением клиента.
